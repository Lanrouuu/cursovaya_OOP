# Функциональность TradeAds

## Авторизация и регистрация

### Регистрация
- Поля: имя пользователя (2–50 символов), email, телефон, пароль (мин. 6 символов), подтверждение пароля
- Валидация email через regex, телефона через regex, уникальность email в БД
- Пароль хранится как SHA-256 хэш
- После успешной регистрации отправляется приветственное письмо (если SMTP настроен)
- Пользователь автоматически авторизуется

### Авторизация
- Вход по email + пароль
- Проверка: пользователь существует, хэш совпадает, аккаунт не заблокирован
- PasswordBox со скрытым вводом (звёздочки) через `PasswordBoxHelper` (attached property)

### Смена пароля
- В личном кабинете: текущий пароль, новый пароль, подтверждение
- Проверяет совпадение текущего пароля, длину нового, совпадение с подтверждением

## Объявления

### Список объявлений
- Отображаются только `Active` объявления (не истёкшие, не скрытые, не заблокированные)
- При загрузке автоматически скрываются просроченные объявления (`ExpireOverdueAsync`)
- **Пагинация:** 10 объявлений на странице, кнопки ← / →, индикатор «Страница X / Y»
- Пустое состояние с иллюстрацией если ничего не найдено

### Поиск и фильтры
| Фильтр | Поведение |
|--------|-----------|
| Текстовый поиск | По названию, краткому описанию, полному описанию, городу, имени продавца |
| Категория | Выпадающий список активных категорий |
| Цена от / до | Числовые поля |
| Город | Частичное совпадение |
| Состояние | Новый / Б/у / Восстановленный |
| Дата от | Объявления, добавленные позже указанной даты |
| Сортировка | Новые, цена ↑, цена ↓, по названию |

Все фильтры применяются мгновенно при изменении (без кнопки «Применить»).

### Карточка объявления
- Изображение, название, цена (или «Бесплатно» если 0)
- Теги: категория, город, дата, состояние, 👁 просмотры, ❤/♡ избранное
- Кнопка «Показать контакты» — открывает email и телефон продавца
- Похожие объявления из той же категории (горизонтальный скролл)
- Счётчик просмотров увеличивается при каждом открытии

### Добавление / редактирование объявления
- Поля: название, краткое и полное описание, цена, категория, состояние, город, контактный email и телефон
- Выбор изображения через диалог или **Drag & Drop** (перетащить файл на превью)
- Допустимые форматы: JPG, JPEG, PNG, GIF, BMP, WEBP
- Изображение копируется в `Assets/UserImages/` с уникальным именем
- Объявление активно 30 дней (поле `ExpiresAt`), после истечения скрывается автоматически

### Статусы объявлений
| Статус | Описание |
|--------|----------|
| Active | Видно всем пользователям |
| Hidden | Скрыто (истёк срок или скрыто администратором) |
| Blocked | Заблокировано администратором |
| Deleted | Удалено (программное удаление, физически остаётся в БД) |

### Удаление
- Пользователь может удалить только своё объявление
- Администратор может удалить любое
- Реализовано как программное удаление: `Status = Deleted`
- Поддерживается Undo: можно отменить удаление

## Избранное

- Кнопка ❤/♡ на каждой карточке объявления
- ♡ — не в избранном (серый), ❤ — добавлено (красный)
- Клик toggles состояние без перезагрузки страницы, счётчик обновляется мгновенно
- Только авторизованным пользователям
- Список избранного в личном кабинете (таблица с активными объявлениями)

## Срок жизни объявлений (30 дней)

- При создании устанавливается `ExpiresAt = DateTime.Now.AddDays(30)`
- При каждом открытии списка объявлений вызывается `ExpireOverdueAsync()` — скрывает истёкшие
- За 3 дня до истечения отправляется email-уведомление (если SMTP настроен)
- В личном кабинете столбец «Истекает» показывает дату
- Кнопка «Продлить» появляется для скрытых объявлений — продлевает на 30 дней и возвращает статус Active

## Личный кабинет

- Редактирование имени, email, телефона
- Смена пароля (отдельная карточка)
- Выбор темы оформления
- Выбор языка интерфейса
- Список своих объявлений с редактированием и продлением
- Список избранных объявлений

## Undo / Redo

- Отмена и повтор для: добавления, редактирования, удаления объявлений
- Кнопки в шапке приложения, активны только когда есть действия в стеке
- Стек не сбрасывается при навигации между разделами

## Темы оформления

| Тема | Цветовая схема |
|------|---------------|
| Light | Светлая, шапка тёмно-синяя |
| Dark | Тёмная, все элементы в тёмных оттенках |
| Optimistic | Тёплая оранжево-янтарная |
| Blue | Холодная сине-голубая |

При первом запуске тема определяется автоматически по системным настройкам Windows (реестр `AppsUseLightTheme`).

## Локализация

- Русский и английский язык
- Переключение мгновенное через замену `ResourceDictionary`
- Все строки интерфейса локализованы (100+ ключей)

## Администрирование

### Пользователи
- Таблица всех пользователей (имя, email, телефон, роль, статус)
- Блокировка / разблокировка аккаунта
- При блокировке / разблокировке отправляется email-уведомление

### Объявления
- Таблица всех объявлений (кроме удалённых) с фильтром по тексту и статусу
- Изменение статуса: Active, Hidden, Blocked
- Удаление объявления
- Экспорт в CSV

### Категории
- Добавление, редактирование, удаление категорий
- Категорию нельзя удалить если к ней привязаны объявления (FK RESTRICT)
- Поле IsActive позволяет скрыть категорию из списка без удаления

### Логи действий
- Таблица последних 200 действий администраторов
- Записываются: изменение статуса объявления
- Поля: дата и время, действие, описание, ID администратора

## Email-уведомления

Настраиваются в `appsettings.json` (секция `Smtp`). Если не настроены — приложение работает без ошибок, письма просто не отправляются.

| Событие | Получатель |
|---------|-----------|
| Регистрация | Новый пользователь |
| Блокировка аккаунта | Заблокированный пользователь |
| Разблокировка аккаунта | Пользователь |
| Блокировка объявления администратором | Автор объявления |
| Активация объявления администратором | Автор объявления |
| 3 дня до истечения объявления | Автор объявления |

## Экспорт данных

Доступен в админ-панели. Формат: CSV с разделителем `;`, кодировка UTF-8.

**Пользователи:** Id, имя, email, телефон, роль, статус блокировки, дата регистрации

**Объявления:** Id, название, цена, категория, продавец, город, статус, просмотры, дата создания, дата истечения
